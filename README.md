#Метод контекстной синонимизации неизвестных токенов из текстов социальных сетей малыми моделями без дообучения


## Описание
Метод интерпретации неизвестных токенов в текстах соцсетей через кластеризацию их контекстов и генерацию синонимов с помощью предобученной MLM-модели (BERT) без дообучения и размеченных данных.
Цель проекта — разработать простой, воспроизводимый способ выделения значений сленговых слов и подбора к ним контекстно-релевантных синонимов в условиях малых выборок и шумных данных.

---

## Структура репозитория

```
/project
├── data/
│   └── fam_annotation.csv          # Размеченные контексты для токена "fam"
├── src/
│   ├── preprocessing.py            # Маскирование целевого токена в текстах
│   ├── embedding.py                # Эмбеддинги BERT (mask/CLS) и TF-IDF
│   ├── clustering.py               # k‑means, агломеративная кластеризация, автовыбор k
│   ├── metrics.py                  # Метрики
│   ├── pipeline.py                 # Основной пайплайн             
├── results/
│   └── results.csv                 # Сохранённые метрики для всех конфигураций
├── slang.ipynb                     # Предобработка данных, фильтрация по языку, отбор кандидатов в сленг
├── run_experiment.ipynb            # Jupyter ноутбук для запуска экспериментов
├── requirements.txt                # Зависимости
└── README.md
```
